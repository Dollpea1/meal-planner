# 🥗 Meal Planner

A clean, responsive, and minimalist Meal Planner web app built with vanilla HTML, CSS, and JavaScript.

No frameworks, no backend, no server, and no database required — all data is automatically stored in the browser using `localStorage`.

**🌐 Live Demo**: [https://dollpea1.github.io/meal-planner/](https://dollpea1.github.io/meal-planner/)

## ✨ Features

- **Add Meals**: Easily plan meals with Meal Name, Day of the week, and Meal Type (*Breakfast*, *Lunch*, *Dinner*, *Snack*).
- **Organized List**: View meals neatly sorted by day of the week and meal type with color-coded badges.
- **Edit Meals**: Update meal details anytime through a clean modal dialog.
- **Delete Confirmation**: Prevent accidental deletions with a confirmation dialog.
- **Live Search**: Instant keyword filtering across meal names, days, and types.
- **Live Meal Counter**: Displays total scheduled meals at the top of the planner.
- **Empty States**: Friendly and helpful empty state messages when starting out or when search results are empty.
- **Mobile Friendly**: Designed to work smoothly on mobile screens as well as tablets and desktops.
- **Data Persistence**: Everything stays saved across page refreshes via `localStorage`.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser — no installation or build steps needed.

```bash
# Clone the repository
git clone https://github.com/Dollpea1/meal-planner.git

# Open the directory
cd meal-planner

# Open index.html in your default browser (or double click the file)
```

## 📁 File Structure

- `index.html` — Semantic markup and app layout
- `style.css` — Modern, responsive styles and theme
- `script.js` — State management, validation, search, and `localStorage` handling
